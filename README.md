This project is a procedural park generator in Maya that randomly creates a park with roads, ponds, fountains, trees, bushes, benches, and lights, with different seasonal color palettes.
To run it, open the Python script in Maya's Script Editor, execute it, and use the GUI to adjust the park settings and click Generate Park.
For future improvements, I would add more types of park objects, improve object placement and variety, make the object placement more realistic, and add more customization options to the GUI.
